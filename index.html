    기간 말 상태

    월별 상세 내역
    이 도구의 성격
    1. 입력값에 대한 결정론적 계산기입니다. 시세·환율은 자동으로 가져오지 않습니다.
    2. 세금은 해외주식 양도세 추정과 파킹통장 이자소득세만 반영합니다. 배당세·재산세·건보료·중도상환수수료·금리 변동은 반영하지 않습니다.
    3. 재무·투자·세무 자문이 아닙니다. 실제 신고는 증권사 양도소득 자료와 홈택스를 기준으로 하십시오.

    설정 · 백업

    자동 동기화 (GitHub 비공개 저장소)

    이 기기에만 저장 중
    이 기기에만 저장되고 다시 표시되지 않습니다
    처음 설정하는 방법
    1. GitHub에서 Private 저장소 networth-data를 만듭니다 (README 체크).
    2. Fine-grained 토큰 발급 → Repository access: Only select repositories → networth-data 하나만 선택.
    3. Permissions → Repository permissions → Contents: Read and write. 나머지는 건드리지 않습니다.
    4. 발급된 토큰을 위 칸에 붙여넣고 저장하고 동기화. 기기마다 한 번씩 합니다.
    5. 토큰은 비밀번호 관리 앱에 보관하십시오. 기기를 바꾸거나 브라우저 데이터를 지우면 다시 입력해야 합니다.
