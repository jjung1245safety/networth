# 자산현황

자산·부채·해외주식·상환 시뮬레이션을 한 화면에서 보는 개인용 웹앱입니다. 휴대폰 홈 화면에 설치할 수 있고, 인터넷이 없어도 열립니다.

## 데이터는 어디에 저장되나

- **이 저장소(공개)에는 코드만 있습니다.** 금액·종목·부동산 같은 개인 데이터는 한 줄도 들어 있지 않습니다.
- 입력한 내용은 **각 기기의 브라우저 저장소**에 즉시 저장됩니다.
- 동기화를 켜면 수 초 뒤 **본인의 비공개(Private) 저장소**에 `data.json`으로 자동 커밋됩니다. 커밋 기록이 곧 버전 기록입니다.
- 토큰은 기기에만 저장되며 코드·저장소 어디에도 기록되지 않습니다.

## 동기화 설정 (기기마다 1회)

1. GitHub에서 **Private** 저장소 `networth-data`를 만듭니다.
2. [Fine-grained 토큰 발급](https://github.com/settings/personal-access-tokens/new)
   - Repository access: **Only select repositories** → `networth-data`
   - Repository permissions → **Contents: Read and write**
3. 앱 ⚙ → 사용자명·저장소·토큰 입력 → **저장하고 동기화**

## 동작 방식

| 상황 | 동작 |
|---|---|
| 편집 | 기기에 즉시 저장, 4초 뒤 자동 전송 |
| 다른 기기에서 수정된 뒤 앱을 열거나 돌아옴 | 최신본을 받아옴 |
| 두 기기에서 동시에 수정 | 덮어쓰지 않고 어느 쪽을 남길지 물음 |
| 오프라인 | 기기에만 저장, 연결되면 자동 전송 |

## 세금 계산 근거

해외주식 양도소득세: 기본공제 연 250만원, 세율 22%(양도소득세 20% + 지방소득세 2%), 과세연도는 결제일 기준 1.1~12.31. 앱의 세액은 현재 환율을 매도일 환율 대신 쓰고 수수료를 빼지 않은 **추정치**입니다. 실제 신고는 증권사 양도소득 자료와 홈택스를 기준으로 하십시오.
